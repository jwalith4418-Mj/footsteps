# Run one deadline-bounded Ollama seat

Once a local table exposes a decision interface, add a localhost Ollama player that receives its own view, legal options and public history. Let the player manage its context and discard stale responses after a deadline. Treat a missing ballot as a public timeout.

Demonstrate one recorded game containing a completed model decision and a timed-out one. Verify that opponents' private information stays outside the request and that the game advances while a model is slow.
