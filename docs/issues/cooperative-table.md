# Run a cooperative baseline with rotating private hands

Solitaire exit-aware play won 789/800 ten-turn games in the first pilot. Measure how that changes at B=0 when builders rotate and see only their own hands.

Implement a seeded cooperative player through the referee's seat view. Hold the post-deal store, goal and tile mix fixed across table sizes. Publish settings, raw outcomes, finish-time distributions, and a replay where control passing matters. Report which differences follow from total supply changing with the number of hands.
