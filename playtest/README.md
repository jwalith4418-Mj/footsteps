# Four-seat paper trial 1

Print [the three-page kit](kit.pdf) at actual size on Letter or A4. The PDF has a 200 × 255 mm page and a 32 mm calibration square. Bring scissors, an opaque bag, and screens for four hands. The PDF includes cut pieces, a turn reference and an observer form. [Full rules](../docs/rules.md)

Use the base-1 rules with three good seats and one bad seat. Deal two tiles to each player from a supply of sixteen, leaving eight turns for a goal six steps away at (4, 2). The trial gives the group two movement opportunities beyond the shortest path. This is a starting point for observing handling and deduction. Its balance at a social table is unmeasured.

For an EXIT-centered session, keep the same physical layout and call EXIT (0, 0) and START (−4, −2). Mark the chosen origin on the observer sheet before the first turn so spoken coordinates and written observations agree.

The sixteen ordinary faces in print order are **188, 153, 16, 71, 45, 91, 121, 41, 234, 12, 44, 16, 74, 107, 41, 182**. This is the pilot generator's seed 0 with independent edge probability 0.55. Shuffle the physical pieces before dealing each session. Face 16 has an outgoing north arrow and no entrance; face 12 has entrances from south and west and no exit. Leave them in the bag mix for the first trial so the table encounters the possibility of one-way traps.

The procedural instructions and tile art are game materials under CC BY 4.0. The Typst source can regenerate the PDF with `typst compile --creation-timestamp 0 playtest/kit.typ playtest/kit.pdf` from the repository root. The PDF was built with Typst 0.15.1, Libertinus Serif and DejaVu Sans.
